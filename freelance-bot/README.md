# Freelance Monitor Bot

Telegram-бот `@myHunterZakazBot` отслеживает вакансии и заказы в публичных Telegram-каналах, фильтрует их по ключевым словам и присылает подходящие варианты владельцу бота.

Платные фриланс-площадки сейчас отключены. Мониторинг работает только для Telegram-каналов и чатов, доступных через публичную веб-ленту `https://t.me/s/<channel>`.

## Возможности

- автоматическая проверка Telegram-источников по расписанию;
- ручная проверка кнопкой или командой `/check`;
- фильтрация каждой вакансии по настраиваемым ключевым словам;
- разбиение сообщений-подборок, например в `@frilans`, на отдельные вакансии;
- защита от повторных уведомлений по идентификатору и отпечатку текста;
- генерация персонального отклика через OpenRouter;
- редактирование каналов, ключевых слов и профиля прямо в интерфейсе бота;
- хранение настроек и истории в SQLite.

## Ограничения текущей версии

- сообщения короче 100 символов пропускаются;
- за один цикл бот присылает не больше пяти подходящих вакансий;
- уведомления отправляются только с 08:00 до 22:00 по московскому времени;
- найденная ночью вакансия уже помечается обработанной и после 08:00 автоматически не повторяется.

## Как обрабатываются Telegram-подборки

Парсер сохраняет переносы строк из Telegram. Если после строки контакта начинается новый профессиональный хэштег, бот создаёт новую вакансию с отдельным стабильным идентификатором. Затем каждая часть независимо проходит проверку длины, дедупликацию и фильтр ключевых слов.

Составные роли с несколькими хэштегами подряд, например `#Сценарист` и `#контентменеджер`, остаются одной вакансией, пока не встретится контакт предыдущей записи.

## Быстрый старт

### 1. Установи Python и зависимости

Требуется Python 3.11 или новее.

```bash
pip install -r requirements.txt
```

### 2. Настрой переменные окружения

Скопируй `.env.example` в `.env` и заполни основные значения:

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от `@BotFather` |
| `USER_ID` | Telegram ID владельца; сообщения других пользователей игнорируются |
| `OPENROUTER_API_KEY` | Ключ OpenRouter для генерации откликов |
| `TG_CHANNELS` | Начальный список каналов через запятую; используется при первом создании базы |
| `CHECK_INTERVAL` | Интервал проверки в секундах, по умолчанию 300 |
| `DATA_DIR` | Необязательная папка для файла SQLite; добавляется вручную и полезна при подключённом постоянном томе |

Для чтения публичных каналов вход в Telegram по номеру телефона не требуется.
Переменные `API_ID` и `API_HASH`, оставленные в `.env.example` для совместимости со старой версией, текущим Telegram-парсером не используются.

### 3. Запусти бота

```bash
python main.py
```

При старте бот создаёт или обновляет базу, выполняет первую проверку Telegram-источников, запускает планировщик и начинает Telegram polling.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | Открывает главное меню и показывает текущие настройки |
| `/check` | Немедленно запускает проверку Telegram-источников |
| `/reply` | Просит прислать найденную вручную вакансию и генерирует отклик |
| `/keywords` | Показывает и редактирует ключевые слова |
| `/channels` | Показывает и редактирует Telegram-каналы |
| `/profile` | Открывает профиль, используемый при генерации откликов |

В главном меню также есть отдельная кнопка «✍️ Написать отклик на вакансию».
Кнопка «📊 Статус» показывает историю обработанных источников, количество Telegram-каналов и ключевых слов, интервал проверки и наличие ключа OpenRouter.

Под каждой найденной вакансией бот показывает две кнопки: «🔗 Открыть заказ» и «✍️ Написать отклик».

## Данные и дедупликация

Файл `seen_orders.db` содержит:

- обработанные вакансии и их источники;
- Telegram-каналы;
- ключевые слова;
- профиль для генерации откликов.

Если таблица каналов или ключевых слов пуста во время запуска, бот снова заполняет её значениями из конфигурации. Поэтому после удаления последнего элемента пустой список восстановится при следующем перезапуске. В остальных случаях настройки меняются через кнопки бота. Записи об обработанных вакансиях старше 30 дней удаляются при инициализации базы.

Для частей одной Telegram-подборки допускается общая ссылка на исходное сообщение: дедупликация по URL для Telegram не применяется, поскольку каждая часть имеет собственный идентификатор и отпечаток текста.

## Проверка изменений

```bash
python -m unittest test_tg_monitoring.py -v
```

Тесты проверяют сохранение переносов строк, корректное разбиение подборок, сохранение составных ролей и уникальность идентификаторов отдельных вакансий.

## Развёртывание в Railway

Railway-сервис использует корневую папку `/freelance-bot`. Команда запуска задана в `railway.toml`:

```toml
[deploy]
startCommand = "python main.py"
restartPolicyType = "always"
```

Переменные окружения задаются в настройках сервиса. Для сохранения SQLite между развёртываниями подключи постоянный том и укажи его путь в `DATA_DIR`.

После push в подключённую ветку Railway автоматически собирает и перезапускает сервис.
