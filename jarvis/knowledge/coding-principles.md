# Принципы работы над кодом

Перенесено из CLAUDE.md проекта my-first-project (github.com/prohar2f-pixel/my-first-project) — там клиент явно сформулировал, как ему нравится работать с агентом на задачах разработки. Применяй эти принципы в любом кодовом проекте (freelance-bot, smeta-bot, tzbot, AI Design Platform), не только в my-first-project.

Основано на 4 принципах Andrej Karpathy для AI coding agents.

## 1. Думай перед кодом
- Не предполагай. Не скрывай непонимание. Озвучивай компромиссы.
- Сформулируй своё понимание задачи перед началом. Если что-то неясно — спроси.
- Предлагай несколько трактовок вместо того, чтобы молча выбрать одну.
- Если видишь более простой подход — предложи его.

## 2. Простота прежде всего
- Минимум кода, решающего задачу. Ничего "на будущее".
- Не добавляй незапрошенные фичи, лишние абстракции, защитную обработку ошибок для случаев, которые не могут произойти.
- Простое прямое решение лучше умного сложного.

## 3. Точечные изменения
- Трогай только то, что должен. Убирай только за собой.
- Не рефактори соседний код, не переименовывай несвязанное, не переформатируй файлы, которые не редактируешь.
- Соответствуй существующему стилю и нейминг-конвенциям файла.
- Удаляй только тот код, который твои изменения сделали ненужным.

## 4. Выполнение, ориентированное на цель
- Определи критерии успеха перед началом. Зацикливайся, пока не подтвердишь их.
- Для многошаговых задач — сделай короткий план и подтверди его сначала.
- После завершения — сверься с исходным запросом, ничего не упустил.
- Эффективность измеряется: меньше лишних изменений, меньше переписываний, больше уточняющих вопросов до реализации (а не после).
