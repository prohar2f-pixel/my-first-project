# Инструкция: Настройка HTTP-сервиса в 1С для интеграции с ассистентом

**Для:** Администратора 1С:Бухгалтерия 8.3  
**Цель:** Создать REST API для получения данных о зарплатах сотрудников  
**Сложность:** Средняя (требуется знание 1С)

---

## Обзор

Нужно создать в 1С три HTTP-эндпоинта:

1. **GET /api/employees** — список сотрудников с окладами
2. **GET /api/salaries/{month}** — начисления и удержания за месяц
3. **GET /api/tax-rates** — справочник налоговых ставок

Ассистент будет вызывать эти эндпоинты для получения свежих данных о зарплате каждый раз, когда бухгалтер его спрашивает.

---

## Способ 1: HTTP-сервисы (рекомендуется для 1С 8.3+)

### Шаг 1: Создание внешних обработок

1. В конфигураторе 1С откройте: **Конфигурация** → **Внешние обработки**
2. Создайте новую обработку с именем `EmployeeDataService`

### Шаг 2: Добавление функций в обработку

В редакторе обработки добавьте следующие процедуры:

```1c
// Возвращает список сотрудников с окладами в JSON формате
Функция ПолучитьСотрудников() Экспорт
    
    Результат = Новый Структура;
    Результат.Вставить("статус", "успешно");
    
    СотрудникиМассив = Новый Массив;
    
    // Запрос из справочника Сотрудники
    Запрос = Новый Запрос(
        "ВЫБРАТЬ
        |   Сотрудники.Ссылка КАК ID,
        |   Сотрудники.Наименование КАК ФИО,
        |   Сотрудники.Должность КАК Должность,
        |   Сотрудники.ДатаРождения КАК ДатаРождения
        |ИЗ
        |   Справочник.Сотрудники КАК Сотрудники
        |ГДЕ
        |   НЕ Сотрудники.ПометкаУдаления
        |   И Сотрудники.Активность"
    );
    
    Выборка = Запрос.Выполнить().Выбрать();
    
    Пока Выборка.Следующий() Цикл
        СотрудникДанные = Новый Структура;
        СотрудникДанные.Вставить("id", Строка(Выборка.ID));
        СотрудникДанные.Вставить("фио", Выборка.ФИО);
        СотрудникДанные.Вставить("должность", Строка(Выборка.Должность));
        СотрудникДанные.Вставить("дата_рождения", Формат(Выборка.ДатаРождения, "ДФ=yyyy-MM-dd"));
        
        СотрудникиМассив.Добавить(СотрудникДанные);
    КонецЦикла;
    
    Результат.Вставить("сотрудники", СотрудникиМассив);
    
    Возврат Результат;
    
КонецФункции


// Возвращает зарплату и удержания для сотрудника за месяц
Функция ПолучитьЗарплату(Месяц, Год) Экспорт
    
    Результат = Новый Структура;
    Результат.Вставить("месяц", Месяц);
    Результат.Вставить("год", Год);
    
    ЗарплатыМассив = Новый Массив;
    
    // Запрос из регистра ЗарплатаКНачислению
    Запрос = Новый Запрос(
        "ВЫБРАТЬ
        |   Регистр.Сотрудник КАК Сотрудник,
        |   Регистр.Сотрудник.Наименование КАК ФИО,
        |   Регистр.ВидРасчета КАК ВидРасчета,
        |   Регистр.Сумма КАК Сумма
        |ИЗ
        |   РегистрСведений.ЗарплатаКНачислению КАК Регистр
        |ГДЕ
        |   МЕСЯЦ(Регистр.Период) = &Месяц
        |   И ГОД(Регистр.Период) = &Год
        |УПОРЯДОЧИТЬ ПО
        |   Регистр.Сотрудник,
        |   Регистр.ВидРасчета"
    );
    
    Запрос.УстановитьПараметр("Месяц", Месяц);
    Запрос.УстановитьПараметр("Год", Год);
    
    Выборка = Запрос.Выполнить().Выбрать();
    
    Пока Выборка.Следующий() Цикл
        ЗарплатаДанные = Новая Структура;
        ЗарплатаДанные.Вставить("сотрудник", Выборка.ФИО);
        ЗарплатаДанные.Вставить("вид_расчета", Строка(Выборка.ВидРасчета));
        ЗарплатаДанные.Вставить("сумма", Выборка.Сумма);
        
        ЗарплатыМассив.Добавить(ЗарплатаДанные);
    КонецЦикла;
    
    Результат.Вставить("зарплаты", ЗарплатыМассив);
    
    Возврат Результат;
    
КонецФункции


// Возвращает справочник налоговых ставок
Функция ПолучитьТарифы() Экспорт
    
    Результат = Новая Структура;
    
    // Жёсткие налоговые ставки на 2024 год (можно вынести в справочник)
    Результат.Вставить("ндфл", 13);
    Результат.Вставить("ес_взнос_сп", 22);      // ЕСН для социального страхования
    Результат.Вставить("ес_взнос_мед", 5.1);   // ЕСН для медицины
    Результат.Вставить("ес_взнос_пенс", 22);   // ЕСН для пенсии
    Результат.Вставить("фсс", 2.9);            // ФСС несчастных случаев
    
    Возврат Результат;
    
КонецФункции
```

### Шаг 3: Публикация как веб-сервис

1. В конфигураторе: **Конфигурация** → **Веб-сервисы** → **Добавить...**
2. Названи: `AccountingAssistantAPI`
3. Метод пространства имён: `http://accounting-assistant.local/api/v1`

Добавьте три операции (методы):
- `GetEmployees` → функция `ПолучитьСотрудников()`
- `GetSalaries` → функция `ПолучитьЗарплату(Месяц, Год)`
- `GetTaxRates` → функция `ПолучитьТарифы()`

### Шаг 4: Публикация на веб-сервере

1. В админ-консоли 1С (веб-интерфейс):
   - Опубликуйте веб-сервис на IIS или Apache
   - URL будет: `http://192.168.1.X:8080/1c/ws/AccountingAssistantAPI`

2. Создайте пользователя для доступа:
   - Логин: `assistant_api`
   - Пароль: безопасный пароль (запишите)

### Шаг 5: Тестирование

Вызовите из браузера или curl:

```bash
curl -u assistant_api:пароль http://192.168.1.X:8080/1c/ws/AccountingAssistantAPI
```

Должны получить описание доступных методов.

## Способ 2: OData (проще, автоматический)

Если вам не хочется писать код в 1С:

1. В админ-консоли 1С перейдите в **Дополнительные параметры**
2. Включите **OData-сервис**
3. URL: `http://192.168.1.X:8080/1c/odata/standard.odata`

OData автоматически предоставит доступ ко всем справочникам и регистрам. 

**Минус:** нужно будет отфильтровать нужные сущности на уровне приложения.

---

## Способ 3: Внешнее соединение (для локальных установок)

Если 1С установлена локально на Windows-сервере компании:

1. На машине с 1С установите Python + `1c-sql-bridge`
2. Запустите локальный сервер, который предоставляет HTTP API
3. Подключайтесь к нему

(Это сложнее, используйте только если веб-сервис не получается)

## Что передать разработчику ассистента

После настройки 1C API, сообщите:

```
API Base URL: http://192.168.1.X:8080/1c/ws/AccountingAssistantAPI
Username: assistant_api
Password: [ваш пароль]
Timeout: 30 сек
```

Разработчик подключит это в `.env` файл приложения.

## Типичные проблемы

| Проблема | Решение |
|----------|----------|
| "Доступ запрещён" | Проверьте права пользователя `assistant_api` в 1С |
| "Метод не найден" | Убедитесь, что функции экспортируются (ключевое слово `Экспорт`) |
| "Таймаут" | Увеличьте время ожидания, проверьте сетевое подключение |
| "Синтаксическая ошибка в запросе" | Проверьте синтаксис SQL в запросах |
