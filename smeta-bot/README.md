# Smeta Bot — AI-агент для поиска цен на строительные материалы

## Что делает бот

1. Принимает PDF строительного проекта
2. Извлекает все наименования материалов
3. Ищет поставщиков и цены по России (Яндекс, сайты поставщиков)
4. Анализирует предложения по цене/качеству/надёжности
5. Сортирует поставщиков: Москва и МО → остальные регионы
6. Отправляет готовую Excel-таблицу с рекомендациями

## Переменные окружения

```
TELEGRAM_TOKEN=токен_от_BotFather
OPENROUTER_API_KEY=ключ_от_openrouter.io
SERPER_API_KEY=ключ_от_serper.dev
```

## Стек

- python-telegram-bot — интерфейс
- openai — клиент для OpenRouter API
- pdfplumber — парсинг PDF
- httpx — запросы к Serper API
- openpyxl — создание Excel-таблиц

## Статус

Готов к запуску. Требует ключи для Telegram, OpenRouter и Serper.
