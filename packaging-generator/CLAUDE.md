# packaging-generator

Самосервисный генератор упаковки для экспертов: онбординг → AI генерирует оффер, текст лендинга и серию писем (последовательно, с управляемыми вариантами). Подробности — в `README.md`. Это Блок 1 цели «полная автоворонка».

## Архитектура

- **Чистая логика — в `src/lib/**`** (онбординг, этапы, варианты, промпты, оценка, БД). Каждый модуль с одной ответственностью и unit-тестом рядом (`*.test.ts`, Vitest). Новую логику добавлять сюда и покрывать тестом — `npm run test`.
- **API-роуты — в `src/app/api/**`**, используют Vercel AI SDK (`ai` v6): `generate` стримит текст (`streamText().toTextStreamResponse()`), `evaluate` возвращает структуру через `generateObject` + zod-схему, `packages` пишет/читает PostgreSQL.
- **UI — в `src/components/**`** и `src/app/page.tsx`. Клиент читает стриминг обычным `fetch` + reader (хуки `@ai-sdk/react` не используются).

## Конвенции

- Генерация — модель **`claude-opus-4-8`** через `@ai-sdk/anthropic` с `baseURL` на **ProxyAPI** (`src/lib/ai/client.ts`). Секреты и URL — только из env, не зашивать.
- **Минимизация данных:** в модель уходит только обезличенный бриф; персональные данные туда не передавать. Хранение — PostgreSQL.
- Промпты и весь текст интерфейса — на русском.
- Next.js версии 16 — перед правкой кода под Next читать `node_modules/next/dist/docs/` (см. `AGENTS.md`), API могут отличаться от обучающих данных.
