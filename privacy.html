Политика обработки персональных данных

1. Общие положения

Сайт aiprohar.ru и его владелец Александр Прохоров осуществляют обработку персональных данных в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О защите персональных данных».

2. Виды собираемых данных

  • При посещении: IP-адрес, тип браузера, операционная система, cookies, время посещения
  • При заполнении форм: имя, email, телефон (если указано)
  • При контакте через Telegram: имя пользователя, сообщения
  • При звонке: номер телефона, информация

3. Цели обработки

  • Ответ на запросы и оказание услуг
  • Заключение и выполнение договоров
  • Улучшение качества сайта и услуг
  • Аналитика и статистика
  • Отправка информационных сообщений (с согласия)
  • Соответствие требованиям законодательства

4. Основания для обработки

  • Выполнение договора
  • Согласие субъекта данных
  • Исполнение юридических обязанностей
  • Законные интересы владельца

5. Системы аналитики

  • Yandex.Metrika: Собирает данные о посещениях, кликах, целевых действиях. Политика Яндекса
  • Cookies: Используются для улучшения работы. Отключаются в настройках браузера

6. Передача данных третьим лицам

Данные не передаются третьим лицам без согласия, кроме:

  • Контрагентов для выполнения услуг
  • Требований законодательства
  • Операторов платежных систем (необходимые данные)

7. Сроки хранения

  • Данные форм: до 3 лет или до расторжения контракта
  • Аналитика: по политике Яндекса
  • Cookies: установленное браузером время

8. Права пользователей

  • Узнать, какие данные обрабатываются
  • Потребовать уточнение, изменение или удаление
  • Отозвать согласие
