# Единый репозиторий сайта aiprohar.ru

**Дата:** 27 июля 2026 года

## Цель

Сайт должен открываться по адресу `https://aiprohar.ru/` без перехода на `/my-first-project/` и поддерживаться из одного канонического репозитория. Используемые боты и приложения должны остаться рабочими и не смешиваться с файлами публичного сайта.

## Инвентаризация

### `prohar2f-pixel/prohar2f-pixel.github.io`

Маленький репозиторий GitHub Pages. Сейчас содержит `CNAME`, технический редирект на `/my-first-project/` и уникальные публичные страницы:

- `kp-realty.html`;
- `statera-preview.html`;
- `tutor-4klass.html`;
- `tales/bk_1.html`;
- `tales/bk_3.html`;
- `tales/bk_6.html`.

### `prohar2f-pixel/my-first-project`

Активный монорепозиторий. В корне находится актуальная версия сайта `aiprohar.ru`, но внутри также находятся используемые боты, приложения, прототипы и документация. Этот репозиторий нельзя удалять или архивировать целиком.

Репозитории имеют независимые истории. Из пяти совпадающих путей только `.nojekyll` и один файл подтверждения Яндекса идентичны. Простая замена или удаление одного репозитория приведёт к потере уникальных данных.

## Архитектура

- `prohar2f-pixel.github.io` становится единственным источником публичного сайта `aiprohar.ru`.
- `my-first-project` остаётся рабочим монорепозиторием ботов, приложений и других проектов.
- GitHub Pages публикует сайт только из ветки `main` репозитория `prohar2f-pixel.github.io`.
- В обоих README фиксируется граница ответственности и ссылка на канонический репозиторий сайта.
- Custom domain `aiprohar.ru` остаётся только в `prohar2f-pixel.github.io`.

## Миграция содержимого

1. Записать исходные хэши веток и создать резервные теги в обоих репозиториях.
2. Скопировать из `my-first-project` в `prohar2f-pixel.github.io` только файлы действующего публичного сайта:
   - основной `index.html`;
   - необходимые файлы из `assets/`;
   - `offer.html`, `privacy.html`, `confidentiality.html` и другие страницы, на которые ссылается основной сайт;
   - `robots.txt`, `sitemap.xml` и актуальные файлы подтверждения поисковых систем;
   - `.nojekyll`.
3. Сохранить уникальные старые страницы `prohar2f-pixel.github.io` в каталоге `legacy/`, не перезаписывая их новыми файлами.
4. Сохранить `CNAME` со значением `aiprohar.ru` в каноническом репозитории.
5. Не переносить в публичный репозиторий ботов, серверный код, внутреннюю документацию, журналы инструментов, кэши и конфигурацию окружения.
6. После успешной публикации удалить из актуальной вершины `my-first-project` только дубли файлов публичного сайта. Их история и резервный тег сохраняются. Используемые проекты и их корневые файлы не изменяются.
7. Отключить GitHub Pages для `my-first-project`, чтобы он больше не создавал вторую опубликованную версию.

Точный перечень удаляемых из `my-first-project` файлов определяется по фактическим зависимостям сайта после миграции. Неоднозначные файлы остаются на месте до отдельного подтверждения.

## DNS и домен

- Существующие четыре A-записи корня на GitHub Pages сохраняются.
- Ошибочная запись `www.aiprohar.ru CNAME www.aiprohar.ru` заменяется на `www CNAME prohar2f-pixel.github.io`.
- После обновления DNS проверяется сертификат и включается принудительный HTTPS в GitHub Pages.

## Защита от повторного расхождения

- README в `my-first-project` прямо запрещает изменять там сайт `aiprohar.ru` и направляет разработчика в канонический репозиторий.
- README в `prohar2f-pixel.github.io` описывает публикацию и проверку сайта.
- Изменения сайта выполняются только в `main` канонического репозитория.
- Перед публикацией проверяется отсутствие секретов, служебных журналов и файлов окружения.
- По возможности для `main` включается защита ветки с обязательной проверкой публикации.

## Проверка

- `https://aiprohar.ru/` показывает актуальный основной сайт без редиректа на `/my-first-project/`.
- `https://www.aiprohar.ru/` разрешается через DNS, работает по HTTPS и приводит к тому же сайту.
- Все используемые CSS, JavaScript, изображения и внутренние ссылки возвращают успешные ответы.
- `offer.html`, `privacy.html`, `confidentiality.html`, `robots.txt`, `sitemap.xml` и подтверждение Яндекса доступны.
- Уникальные старые страницы открываются из `legacy/`.
- Боты и приложения из `my-first-project` проходят свои штатные проверки или, если общей проверки нет, их файлы и конфигурация остаются неизменными.
- GitHub Pages для `my-first-project` больше не является источником публичного сайта.

## Откат

До миграции создаются резервные теги обоих репозиториев. При проблеме домен остаётся привязанным к `prohar2f-pixel.github.io`, а его содержимое возвращается к резервному тегу. Изменения `my-first-project` выполняются только после успешной публикации нового сайта и также могут быть возвращены по тегу или отдельным коммитом.

Удаление репозитория, переписывание Git-истории и удаление используемых проектов в эту работу не входят.
