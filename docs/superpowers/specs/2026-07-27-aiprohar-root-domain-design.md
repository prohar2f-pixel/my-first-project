# Перенос aiprohar.ru на корень сайта

**Дата:** 27 июля 2026 года

## Цель

Сайт из репозитория `prohar2f-pixel/my-first-project` должен открываться по адресу `https://aiprohar.ru/` без перехода на `/my-first-project/`. Вариант с `www` должен работать по HTTPS и приводить к тому же сайту.

## Текущее состояние

- DNS домена обслуживается Beget.
- Корневой домен направлен четырьмя A-записями на GitHub Pages.
- Custom domain `aiprohar.ru` закреплён файлом `CNAME` за репозиторием `prohar2f-pixel/prohar2f-pixel.github.io`.
- `index.html` этого репозитория перенаправляет посетителя на `/my-first-project/`.
- Основной сайт находится в репозитории `prohar2f-pixel/my-first-project`.
- DNS-запись `www` зациклена: `www.aiprohar.ru CNAME www.aiprohar.ru`, поэтому запросы завершаются `SERVFAIL`.

## Решение

1. Удалить привязку custom domain и перенаправление из `prohar2f-pixel.github.io`.
2. Добавить в корень `my-first-project` файл `CNAME` со значением `aiprohar.ru`.
3. Оставить текущие A-записи корневого домена GitHub Pages без изменений.
4. В DNS Beget заменить зацикленную запись `www` на `CNAME` со значением `prohar2f-pixel.github.io`.
5. После подтверждения домена GitHub Pages включить принудительный HTTPS.

Custom domain может быть назначен только одному GitHub Pages-сайту одновременно. Поэтому изменения репозиториев выполняются в порядке: сначала освободить домен в пользовательском репозитории, затем назначить его проектному репозиторию.

## Проверка

- `https://aiprohar.ru/` возвращает основной HTML сайта и не содержит редирект на `/my-first-project/`.
- `https://www.aiprohar.ru/` разрешается через DNS, открывается по HTTPS и приводит к основному сайту.
- CSS, JavaScript, изображения и внутренние ссылки работают от корня домена.
- Сертификат действителен для используемых имён.
- Файлы и метатеги подтверждения Яндекса остаются доступны.
- `https://aiprohar.ru/my-first-project/` не используется как основной публичный адрес; его дальнейшая доступность не является обязательной.

## Безопасность и откат

- Секреты и локальные файлы не добавляются в коммиты.
- Изменения каждого репозитория оформляются отдельным целевым коммитом.
- Откат выполняется возвратом `CNAME` и редиректа в `prohar2f-pixel.github.io`, удалением `CNAME` из `my-first-project` и восстановлением прежней DNS-записи `www` только при необходимости.
