# КП-агент — Спецификация

**Дата:** 2026-06-17  
**Статус:** Ready for implementation  
**Автор:** Discovery Interview (Jarvis)

---

## Executive Summary

Отдельный Telegram-бот для Александра, который автоматизирует создание коммерческих предложений на разработку сайтов. Пользователь кидает ссылку на организацию → бот поэтапно (с одобрением на каждом шаге) собирает информацию, генерирует ТЗ, ждёт HTML-дизайн от пользователя, копирует его пиксель-в-пиксель, деплоит на Netlify, создаёт HTML-презентацию КП и готовит скрипты переписки с клиентом.

---

## Problem Statement

Создание КП для потенциального клиента-сайта занимает у Александра несколько часов: изучить компанию, написать ТЗ, сделать дизайн, сверстать сайт, собрать КП, написать первое сообщение. Всё это — ручная работа. Цель — сократить время на одно КП с нескольких часов до 15–20 минут активного участия, при объёме 5–10 КП в неделю.

---

## Success Criteria

- Одно КП проходит весь цикл за ≤60 минут (от ссылки до отправки)
- Александр тратит ≤20 минут активного времени на КП (остальное — фоновая работа бота)
- Сайт-превью открывается по ссылке Netlify и выглядит профессионально
- КП сделано в стиле шаблона `kp-u-yulii.html`
- Конверсия КП → ответ клиента ≥30%

---

## User Persona

**Александр** — разработчик сайтов и AI-решений. Работает один. Ищет клиентов в 2ГИС, Яндекс.Картах, соцсетях. Сам генерирует HTML-дизайн через ChatGPT (это его творческий инструмент, автоматизация не нужна). Технически грамотен. Ценит контроль — хочет одобрять каждый этап.

---

## User Journey (9 шагов)

### Шаг 1 — Ввод ссылки
Александр отправляет боту ссылку на организацию:
- Карточка в 2ГИС / Яндекс.Картах
- Страница ВКонтакте / Instagram
- Существующий слабый сайт компании

Бот подтверждает: *«Принял. Начинаю исследование компании...»*

---

### Шаг 2 — Исследование компании (авто)
Бот самостоятельно собирает:
- Название, сфера деятельности, гео
- Существующий сайт (если есть): скорость, дизайн, мобильность, наполнение
- Контакты: телефон, email, мессенджеры (если находит в интернете)
- Соцсети и активность
- Конкуренты в нише (топ-3 по запросам)
- «Боли»: что клиенту не хватает для продаж (нет сайта / устаревший / нет SEO / нет заявок)

Источники: WebSearch + WebFetch по ссылке + поиск по названию компании.

По завершении бот отправляет **сводку** и спрашивает: *«Исследование завершено. Всё верно? Продолжаем?»*  
Кнопки: `✅ Продолжить` / `✏️ Уточнить`

---

### Шаг 3 — Утверждение брифа
Александр читает сводку, нажимает «Продолжить» или вносит правки голосом/текстом.

---

### Шаг 4 — Внутреннее ТЗ-интервью (авто)
Бот **самостоятельно** (без tzbot) проводит интервью по вопросам ТЗ:
- Тип сайта (лендинг / корпоративный / каталог)
- Структура страниц и блоков
- Целевая аудитория
- УТП и ключевые смыслы
- Цветовая гамма / стиль
- Функциональность (формы, карты, калькуляторы)
- Интеграции (CRM, WhatsApp, Telegram)

Бот сам отвечает на эти вопросы на основе исследования из шага 2 и генерирует ТЗ-документ.

По готовности отправляет ТЗ в чат: *«Вот ТЗ на сайт. Подтверждаешь?»*  
Кнопки: `✅ Подтвердить` / `✏️ Скорректировать`

---

### Шаг 5 — Получение HTML-дизайна (ручной шаг)
Бот: *«Теперь твоя очередь. Сгенерируй дизайн в ChatGPT на основе ТЗ и пришли мне HTML-файл.»*

Бот прикрепляет к сообщению **готовый промпт для ChatGPT** — на основе ТЗ.

Александр генерирует дизайн, отправляет `.html`-файл боту.

---

### Шаг 6 — Создание сайта-превью (авто)
Бот получает HTML-дизайн и:
1. Изучает структуру, цвета, шрифты, блоки
2. Генерирует **полноценный сайт** на основе дизайна:
   - Заполняет реальным контентом о компании (из шага 2)
   - Соблюдает каждый дизайн-элемент пиксель-в-пиксель
   - Адаптирует под мобильные
   - Добавляет рабочие формы (Telegram-webhook)
3. Деплоит на **Netlify** через API → получает уникальную ссылку

По готовности: *«Сайт готов: https://... Проверь — если всё ок, продолжаем с КП.»*  
Кнопки: `✅ Отлично, делаем КП` / `✏️ Правки`

---

### Шаг 7 — Генерация HTML-КП (авто)
Бот создаёт HTML-презентацию КП в стиле шаблона `kp-u-yulii.html`:

**Структура КП:**
1. **Шапка** — имя компании-клиента, дата, от Александра
2. **Анализ текущего сайта** — скриншот/описание проблем (почему он слабый)
3. **Превью нового сайта** — ссылка + скриншот из Netlify, ключевые преимущества
4. **Что входит в работу** — список блоков из ТЗ
5. **Прайс и сроки** — из прайс-листа Александра по категории сайта
6. **Об Александре** — краткое портфолио, контакты

Бот отправляет HTML-файл + превью: *«КП готово. Проверь — подтверждаешь?»*  
Кнопки: `✅ Подтвердить` / `✏️ Правки`

---

### Шаг 8 — Согласование (ручной шаг)
Александр открывает КП, проверяет всё лично. При необходимости — диктует правки боту текстом/голосом. Бот вносит и снова показывает.

После подтверждения бот деплоит финальное КП на Netlify (отдельный URL).

---

### Шаг 9 — Скрипты для переписки
Бот готовит набор сообщений для Александра:

1. **Первое сообщение** (холодное обращение) — короткое, живое, без канцелярщины. Упоминает конкретную проблему этой компании.
2. **Сообщение с КП** — 2-3 строки + ссылка на КП
3. **Follow-up через 2 дня** — если нет ответа
4. **Ответы на типичные возражения** (дорого / уже есть сайт / не сейчас)

Каждое сообщение — в отдельном блоке, готово к копипасту.

Бот: *«Вот скрипты. Копируй и отправляй в нужный момент. Удачи!»*

## Functional Requirements

### P0 — Must Have
- Принять любую ссылку (2ГИС, Яндекс.Карты, ВКонтакте, Instagram, сайт)
- Вебсёрч + парсинг страниц для исследования компании
- Генерация ТЗ-документа на основе данных (без tzbot)
- Генерация промпта для ChatGPT
- Приём HTML-файла от пользователя
- Генерация полноценного HTML-сайта с реальным контентом
- Деплой на Netlify через API → живая ссылка
- Генерация КП в HTML в стиле шаблона
- Прайс-лист в конфиге (категории сайтов → цена)
- Шаговый флоу с кнопками одобрения на каждом этапе
- Генерация скриптов переписки
- Прогресс в чате (что делает бот в реальном времени)

### P1 — Should Have
- Промпт для ChatGPT автоматически формируется из ТЗ и прикрепляется к запросу дизайна
- КП деплоится отдельной ссылкой на Netlify (не только сайт)
- Правки по тексту/голосу на любом этапе
- Хранение всех КП с историей (SQLite или файлы)
- Команда `/history` — список прошлых КП

### P2 — Nice to Have
- Скриншот сайта-превью прямо в чат (через Playwright/Puppeteer)
- Автоматический follow-up напоминатель через N дней
- Статистика конверсии (отправлено КП → ответили → закрыли)

## Technical Architecture

### Стек
- **Язык:** Node.js (как и Jarvis-бот, единая экосистема)
- **Telegram:** grammy
- **Веб-парсинг:** undici + cheerio (или playwright для JS-сайтов)
- **Поиск:** Serper API (уже есть у Александра) или Claude WebSearch
- **AI:** Anthropic Claude API — исследование, ТЗ, генерация сайта, КП, скрипты
- **Деплой превью:** Netlify API (Deploy via zip upload — не нужен git)
- **БД:** SQLite (sql.js) — сессии, история КП
- **Хостинг бота:** Railway (как tzbot и smeta-bot)

### Модель данных

```
Project {
  id: uuid
  created_at: timestamp
  status: 'researching' | 'tz' | 'awaiting_design' | 'building' | 'review' | 'done'
  org_link: string          // исходная ссылка
  org_data: JSON            // результат исследования
  tz: JSON                  // ТЗ-документ
  design_html: string       // полученный от пользователя HTML
  site_html: string         // сгенерированный сайт
  site_url: string          // Netlify preview URL
  kp_html: string           // HTML-КП
  kp_url: string            // Netlify КП URL
  scripts: JSON             // скрипты переписки
  price: number             // итоговая цена из прайс-листа
}
```

### Флоу состояний

```
START → RESEARCHING → AWAITING_APPROVAL_1
     → GENERATING_TZ → AWAITING_APPROVAL_2
     → AWAITING_DESIGN (ждём HTML от пользователя)
     → BUILDING_SITE → AWAITING_APPROVAL_3
     → GENERATING_KP → AWAITING_APPROVAL_4
     → DONE (скрипты готовы)
```

### Netlify Deploy API

Без Git. Загрузка через `/deploys` endpoint:
```
POST https://api.netlify.com/api/v1/sites/{site_id}/deploys
Content-Type: application/zip
Authorization: Bearer {NETLIFY_TOKEN}
```
Каждый проект = отдельный Netlify site. Уникальный subdomain: `kp-{uuid}.netlify.app`

### Прайс-лист (конфиг)

```js
const PRICE_LIST = {
  landing:     { label: 'Лендинг',          price: 25000, days: 5 },
  corporate:   { label: 'Корпоративный',    price: 45000, days: 10 },
  catalog:     { label: 'Каталог товаров',  price: 65000, days: 14 },
  ecommerce:   { label: 'Интернет-магазин', price: 90000, days: 21 },
};
```

## Non-Functional Requirements

- **Производительность:** весь автоматический флоу (шаги 2, 4, 6, 7) ≤30 минут
- **Надёжность:** состояние сохраняется в SQLite — перезапуск бота не сбрасывает прогресс
- **Масштаб:** 5–10 КП/неделю (Netlify free tier: 500 sites, 100GB — достаточно)
- **Безопасность:** только Александр использует бота (OWNER_ID lock, как в Jarvis)
- **Логирование:** каждый шаг логируется в файл для дебага

---

## Out of Scope

- Авто-отправка сообщений клиентам через Telegram (только скрипты)
- SEO оптимизация готового сайта
- CMS или панель управления для клиента
- Мультипользовательский режим
- Автоматическая генерация дизайна без ChatGPT
- Интеграция с tzbot (логика встроена напрямую)
