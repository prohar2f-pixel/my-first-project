## Пример 1: Freelancer Auto-Bid Bot (n8n)

**Тип:** n8n workflow-шаблон, open-source  
**Ссылка:** https://n8n.io/workflows/6048-freelancer-auto-bid-bot-ai-proposals-with-telegram-approval/

### Задача
Автоматически находит проекты на Freelancer.com по ключевым навыкам, генерирует персонализированное предложение через AI и отправляет тебе на одобрение в Telegram — одним нажатием кнопки.

### Функции
- Поиск активных проектов через Freelancer.com API по заданным навыкам
- Проверка дубликатов (не предлагает на проект дважды)
- Сбор данных о проекте: описание, бюджет, требования
- AI-генерация «короткого, убедительного, персонализированного» предложения (OpenAI)
- Telegram-уведомление с кратким резюме проекта
- Встроенные кнопки в чат: **Bid** / **Cancel**
- После нажатия «Bid» — автоматическая подача ставки с заданными параметрами (сумма, сроки)

### Типичный диалог в Telegram
```
🤖 Новый проект: "Python Django + n8n automation for CRM"
💰 Бюджет: $500–800
⏱ Срок: 2 недели

Сгенерированное предложение:
"Я занимаюсь автоматизацией на n8n и Django уже 3 года.
Ваша задача — именно тот тип интеграции, который я делал
для [схожий кейс]. Готов обсудить детали и начать сразу."

[✅ Bid] [❌ Cancel]
```

### Что делает его полезным
- Ты тратишь 3 секунды вместо 15 минут на каждое предложение
- AI пишет под конкретный проект, а не шаблонно
- Human-in-the-loop: ты контролируешь каждую ставку
- Работает по расписанию: ищет проекты каждый час

### Что взять в КП-агент
✅ Паттерн «Telegram-кнопки одобрения» на каждом этапе  
✅ Краткое резюме перед кнопками (не полный текст, а саммари)  
✅ Блокировка отправки без одобрения пользователя  
✅ Проверка дубликатов — у нас аналог: не делать два КП для одной компании

## Пример 2: AI Sales Bot с квалификацией BANT (BotSeller.ai)

**Тип:** SaaS-платформа для создания Telegram-ботов продаж  
**Ссылка:** https://botseller.ai/blog/telegram-bot-dlya-prodazh

### Задача
Принимает входящие обращения клиентов в Telegram, квалифицирует их по системе BANT (Budget, Authority, Need, Timeline), снимает возражения и записывает на встречу. Работает 24/7 вместо менеджера.

### Функции
- Анализ свободного текста через нейросеть (не жёсткие скрипты)
- Распознавание голосовых сообщений (Whisper: 15–30 сек)
- BANT-квалификация: собирает бюджет, полномочия, потребность, сроки
- Контекстная память: помнит всю переписку в сессии
- Интеграция с amoCRM, Битрикс24: горячие лиды падают с историей
- Обработка возражений по заранее настроенным сценариям

### Типичный диалог
```
Клиент: Сколько стоит сайт?
Бот: Зависит от задачи. Расскажите — это лендинг для привлечения
     клиентов или корпоративный сайт компании?

Клиент: Для записи в салон красоты
Бот: Понятно! Примерный бюджет на разработку у вас есть?
     Или нужна оценка?

Клиент: Ну тысяч 30-40
Бот: Отлично, это реалистично для такого проекта. Когда планируете
     запуск — к конкретной дате или без жёстких сроков?
```

### Результаты (из кейсов)
- Турагентство: 1 749 заявок/мес через бота
- B2B стройматериалы: 1 263 клиента через несколько каналов
- Конверсия у менеджеров выросла: они работают только с горячими лидами

### Что делает его полезным
- Не ломается при нестандартных ответах (в отличие от кнопочных ботов)
- Определяет готовность к покупке до того, как подключается человек
- Экономит 60% времени менеджеров на первичную обработку

### Что взять в КП-агент
✅ BANT-структура при сборе данных об организации (Бюджет клиента? Кто решает? Зачем сайт? К какой дате?)  
✅ Живые вопросы, не анкета — бот задаёт их одним за раз, как в разговоре  
✅ Квалификация «горячести» клиента перед созданием КП (стоит ли тратить ресурс?)  
✅ Голосовые сообщения — Александр может надиктовывать правки

## Пример 3: Make.com → GPT-4 → PandaDoc (HomeFront Media)

**Тип:** No-code automation для digital-агентств  
**Ссылка:** https://homefrontmediagroup.com/post/free-custom-proposals  
**Стоимость:** $0.30–0.50 за одно КП, $59–94/мес на 30 КП

### Задача
Генерирует персонализированное КП для нового клиента за 60 секунд после встречи. Фрилансер заполняет форму за 2 минуты — остальное делает автоматизация.

### Как работает (8 модулей в Make.com)
1. **Typeform**: форма с полями после встречи — название компании, проблема, решение, инструменты, сроки, бюджет
2. **Фильтр**: если исход встречи ≠ «Отправить КП» → процесс останавливается (экономия токенов)
3. **GPT-4 вызов #1**: анализ проблем + описание решения
4. **GPT-4 вызов #2**: генерация 4 этапов проекта с дедлайнами
5. **PandaDoc API**: заполнение шаблона → готовый документ к отправке

### Few-shot персонализация
В промпт включены **два примера реальных КП** этого агентства. GPT-4 учится стилю и структуре. По данным OpenAI, это улучшает качество на 40–60% по сравнению с нулевым промптом.

### Структура итогового КП
- Титульный лист с логотипом
- Анализ текущих проблем клиента (AI-написанный)
- Предложенное решение с аргументацией
- 4 этапа с дедлайнами (например: «MVP за 7–10 дней»)
- Таблица цен с разбивкой
- Поле для подписи

### Ключевой инсайт из исследования PandaDoc
> «КП, отправленные в течение 24 часов после разговора, закрываются в **3 раза чаще**, чем отправленные позже»

### Что взять в КП-агент
✅ **Few-shot подход**: при обучении промпта использовать `kp-u-yulii.html` как пример  
✅ **Фильтр целесообразности**: перед созданием КП проверять, стоит ли (нет сайта / слабый сайт / реальный бюджет)  
✅ **Скорость = конверсия**: цель — КП через час после того как увидел организацию  
✅ Разбивка на этапы + дедлайны в КП повышает доверие

✅ Паттерн «шаблон → заполнение AI-контентом» — переносится на HTML КП  
✅ Google Slides → в нашем случае HTML-шаблон по `kp-u-yulii.html`

## Пример 5: UpHunt — Автоматизированный Pipeline для фрилансеров

**Тип:** SaaS-продукт, полный цикл поиска клиентов  
**Ссылка:** https://uphunt.io

### Задача
Полная автоматизация бизнес-девелопмента фрилансера: от поиска проекта до отправки предложения.

### Три модуля
1. **Opportunity Discovery**: мониторит несколько платформ (Upwork, LinkedIn, GitHub Jobs) — находит релевантные заказы
2. **Client Research & Qualification**: автоматически исследует клиента перед созданием предложения
3. **Personalized Proposal Generation & Submission**: генерирует и отправляет кастомное предложение

### Ключевой паттерн: Исследование перед предложением
Система исследует клиента **до** написания — не просто подставляет имя, а включает специфику бизнеса в текст. Это отличает персонализированное предложение от массового.

### Что взять в КП-агент
✅ **Трёхэтапный паттерн**: Найти → Исследовать → Предложить — точно наш флоу  
✅ **Qualification до создания КП**: стоит ли делать это КП? Проверить: есть ли контакты, активен ли бизнес, нужен ли сайт  
✅ Multi-source research: 2ГИС + Яндекс + соцсети + существующий сайт = полная картина

## Пример 6: Qwilr — Интерактивные веб-КП

**Тип:** SaaS, $35–59/пользователь/месяц  
**Ссылка:** https://qwilr.com

### Задача
Создаёт КП в формате красивой веб-страницы (не PDF) с отслеживанием просмотров, встроенными видео и онлайн-подписью.

### Ключевые функции
- КП = живая веб-страница с уникальным URL (не PDF!)
- Трекинг: когда открыли, сколько времени читали, на каком блоке остановились
- Встроенные видео-приветствия (персонализация через Loom)
- Онлайн-подпись прямо в браузере
- Автоприменение брендинга: цвета, логотип — один раз настроил, везде работает
- Интеграция с HubSpot, Salesforce

### Почему это важно для нашего контекста
Qwilr доказал, что **веб-КП работает лучше PDF**:
- Можно обновить КП после отправки (клиент видит актуальную версию)
- Аналитика: видишь, прочитали ли вообще
- Мобильная адаптация из коробки
- Ссылку проще переслать, чем файл

### Что взять в КП-агент
✅ **КП как веб-страница** (HTML на Netlify) — а не PDF — именно это и запланировано  
✅ **Уникальная ссылка для каждого клиента** — подтверждение правильности архитектуры  
✅ Идея для P2: добавить трекинг открытий через Cloudflare Analytics или простой пиксель  
✅ Видео-приветствие от Александра = killer feature на будущее (Loom API + автовставка)

## Пример 7: Gigradar — AI Co-pilot для фрилансера

**Тип:** SaaS, lead generation для фрилансеров  
**Ссылка:** https://gigradar.io

### Задача
AI co-pilot для привлечения клиентов: находит горячие лиды и составляет персонализированные cold outreach письма.

### Как работает персонализация outreach
- Анализирует профиль и историю компании-клиента
- Находит «точку боли» конкретного бизнеса
- Пишет первое сообщение с упоминанием конкретной проблемы этой компании
- Не шаблон — каждое письмо уникально

### Ключевой инсайт
> Персонализированный cold outreach с упоминанием конкретной проблемы клиента = в разы выше ответная реакция, чем общие «Привет, мы делаем сайты»

### Что взять в КП-агент
✅ **Скрипты для Александра должны быть персонализированными** — не «Привет, я делаю сайты», а «Заметил, что у вас на сайте нет формы заявки, хотя вы принимаете заказы — теряете лиды»  
✅ Первое сообщение = конкретная проблема + мягкое приглашение — не продажа в лоб  
✅ Структура скрипта: Наблюдение → Проблема → Зацепка → Призыв к действию

## Ключевые инсайты для доработки спецификации

### 1. Добавить шаг «Квалификация» (между шагом 1 и 2)
Перед ресёрчем бот должен быстро проверить:
- Можно ли найти контакты компании в интернете?
- Активен ли бизнес (работает / есть соцсети / есть отзывы)?
- Есть ли признаки что им нужен сайт (нет сайта / сайт 2010 года)?

Если нет — сообщить Александру: «Компания не найдена / контактов нет — пропускаем?»

### 2. Few-shot обучение промпта на примере kp-u-yulii.html
Не просто «сделай КП в таком стиле» — а включить HTML-код примера в system prompt. GPT/Claude учится на конкретном примере лучше чем на описании.

### 3. Структура первого скрипта — от боли, не от себя
**❌ Плохо:** «Привет, я Александр, делаю сайты, вот моё КП»  
**✅ Хорошо:** «Привет, смотрел ваш сайт — у вас нет формы обратной связи на мобильном. Сделал набросок как это может выглядеть — можно покажу?»

### 4. Трекинг просмотра КП (P2 → возможно P1)
Простой fetch-пиксель (1px img) в HTML КП → Александр знает когда клиент открыл → правильный момент для follow-up. Технически: Cloudflare Worker логирует запросы.

### 5. Скорость как конкурентное преимущество
По данным PandaDoc: КП в течение 24 часов после первого контакта закрываются в **3× чаще**. Архитектура должна обеспечивать полный цикл за одну рабочую сессию (1–2 часа).

### 6. Промпт для ChatGPT — это ключевой продукт бота
Автоматически сгенерированный промпт из ТЗ — это то, что экономит Александру максимум времени на шаге 5. Промпт должен содержать: цветовую гамму, тип бизнеса, структуру блоков, референсы стиля.

## Чего нет на рынке (наш дифференциатор)

Ни один найденный инструмент не делает следующее в связке:
1. Принимает ссылку на организацию из 2ГИС/соцсетей (не из CRM или формы)
2. Сам исследует без участия пользователя
3. Строит реальный работающий сайт (не просто PDF-документ)
4. Деплоит превью на хостинг
5. Генерирует КП со ссылкой на живой сайт

Это то, что делает КП-агент уникальным инструментом.
