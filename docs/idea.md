# @ProharContentBot — Идея

**ИИ-агент, который генерирует вирусный контент для соцсетей, автоматически публикует его и анализирует что работает — чтобы привлекать клиентов на разработку сайтов и ИИ-агентов.**

---

## 1. ЧТО ДЕЛАЕТ

1. Собирает информацию (тренды IT/ИИ + портфолио автора + анализ конкурентов)
2. Генерирует черновики через Claude API: текст поста + сценарий для видео (Reels/Shorts)
3. Предлагает черновики в Telegram для одобрения → кнопки [✅ Опубликовать] [✏️ Изменить] [❌ Отменить]
4. После одобрения — публикует одновременно в Telegram-канал и VK
5. Через несколько дней — собирает аналитику (просмотры, лайки, комментарии)
6. Показывает: какие темы/форматы работают лучше
7. Цель финальной версии — видеть связь: этот пост → привёл клиента в @prohar_tz_bot

---

## 2. ДЛЯ КОГО

Широкая аудитория без жёсткого сегмента — все, кто может стать клиентом на:
- Разработку сайтов
- Создание Telegram-ботов
- ИИ-интеграции / ИИ-агентов

---

## 3. ОТКУДА БЕРЁТ ИНФОРМАЦИЮ

| Источник | Что даёт |
|----------|----------|
| Тренды интернета | Актуальные темы в IT, ИИ, вирусные инфоповоды |
| Портфолио/кейсы автора | Реальные истории и результаты для доверия |
| Контент конкурентов | Что работает у других разработчиков/студий |

---

## 4. ГДЕ ЖИВЁТ

- **Интерфейс:** Telegram-бот `@ProharContentBot` — все взаимодействия через него
- **Сервер:** Удалённый сервер Jarvis (`C:\Users\Administrator\Documents\Projects\content-bot\`)
- **Отдельный процесс:** не смешивается с другими ботами на том же сервере

---

## 5. ЧТО ВЫДАЁТ

**Фаза 1 (старт):**
- Telegram-канал (автопубликация через Telegram Bot API)
- VK (автопубликация через VK API)

**Фаза 2 (после настройки доступов):**
- Instagram (Instagram Graph API — требует Meta Business)
- YouTube / Shorts (YouTube Data API v3 — требует Google Cloud OAuth)

**Частота:** 2-3 публикации в неделю по расписанию

**Формат:** текст (пост/подпись) + сценарий для видео 30-60 сек (видео снимает сам автор)

---

## Технические решения

| Параметр | Решение |
|----------|---------|
| Язык | Python |
| Telegram-фреймворк | aiogram (как в freelance-bot) |
| ИИ для генерации | Claude API (Anthropic) |
| База данных | SQLite (история постов, аналитика) |
| Расписание | apscheduler |
| Сервер | Jarvis Windows VPS |

---

## Аналитика (что трекать)

- Просмотры / лайки / комментарии каждого поста
- Рейтинг тем: какие темы набирают больше всего охвата
- Рейтинг форматов: текст vs история vs кейс
- **Финальная цель:** связь конкретного поста → заявка в @prohar_tz_bot
