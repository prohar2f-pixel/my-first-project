# Исследование: сервис упаковки и автоворонки для экспертов

> Дата: 2026-06-23. Три темы исследовали 3 агента параллельно. Все примеры — реальные, со ссылками на источники.

---

## 1. Простота и удобство

Как сделать интерфейс таким, чтобы человек разобрался без инструкции.

### Источники (реальные сервисы/репозитории)

- **Social-Media-Post-Generator (0xmetaschool)** — генератор постов для соцсетей на Next.js: один экран, тема + тон + платформа. https://github.com/0xmetaschool/Social-Media-Post-Generator
- **Creator-AI (shohail-DeV)** — набор AI-инструментов (заголовки, посты, описания товаров) с готовыми шаблонами-карточками. https://github.com/shohail-DeV/Creator-AI
- **aipage.dev (zinedkaloc)** — генератор лендингов: одно поле «опиши свой сайт» + живой предпросмотр в iframe. https://github.com/zinedkaloc/aipage.dev
- **alwrity-pas (AJaySi)** — копирайтер по формуле PAS на Streamlit: 5 коротких полей, на выходе 3 варианта текста. https://github.com/AJaySi/alwrity-pas
- **CopywriterProAI (frontend)** — open-source платформа AI-копирайтинга (блоги, реклама, лендинги). https://github.com/CopywriterPro-ai/copywriterproai-frontend
- **Vercel Chatbot / AI SDK** — эталон потокового вывода текста по словам и кнопок-подсказок. https://github.com/vercel/chatbot · https://github.com/vercel/ai

### 5-7 приёмов простоты

1. **Один экран без меню и без шагов.** Всё на одной странице: ввёл — нажал — получил результат рядом. Никаких «далее/назад». *Чем хорош:* человек видит задачу целиком и не боится «застрять» посередине. *Откуда:* Social-Media-Post-Generator, aipage.dev.

2. **Готовый пример прямо в поле ввода (placeholder).** В поле уже написан образец: у aipage.dev — *«A landing page for a design studio located in New York…»*; у PAS-копирайтера подсказки в полях. *Чем хорош:* снимает страх чистого листа, показывает тему/длину/стиль. *Откуда:* aipage.dev, alwrity-pas.

3. **Готовые карточки-шаблоны вместо настройки с нуля.** В Creator-AI выбираешь карточку («Заголовок поста», «Описание товара»), под неё показываются только нужные поля. *Чем хорош:* человек выбирает задачу человеческими словами, без «параметров». *Откуда:* Creator-AI.

4. **Минимум полей, и они короткие.** У PAS-копирайтера 5 полей с подсказкой *«(In 5-6 words)»*. *Чем хорош:* короткая форма не пугает, заполняется за минуту, подсказка про длину защищает от ступора. *Откуда:* alwrity-pas, Creator-AI.

5. **Понятная кнопка действия словами задачи.** Кнопки названы по результату: *«Generate Posts»*, *«Get PAS Copy»*, а не «Отправить». *Чем хорош:* человек заранее понимает, что произойдёт. *Откуда:* Social-Media-Post-Generator, alwrity-pas.

6. **Результат сразу рядом + кнопка «Копировать».** Готовый текст показывается тут же, у каждого результата своя кнопка copy; у aipage.dev — живой iframe-предпросмотр. *Чем хорош:* не надо искать «куда делся текст», забрать результат — один клик. *Откуда:* Social-Media-Post-Generator, aipage.dev.

7. **Несколько вариантов за раз + потоковый вывод по словам.** PAS-копирайтер выдаёт 3 варианта; эталон «печатается по словам» — Vercel AI SDK. *Чем хорош:* есть из чего выбрать без повторной генерации; текст по словам показывает, что система работает (пустая крутилка пугает сильнее). *Откуда:* alwrity-pas, vercel/ai.

### Что берём в наш проект

- **Один экран, без меню**: поле для брифа → кнопка → результат под ним.
- **Старт через карточки задач** человеческими словами: «Упаковать продукт», «Текст для лендинга», «Серия писем для воронки». Под каждую — 1-3 коротких поля.
- **В каждом поле — живой пример-плейсхолдер** под психолога/коуча (напр.: «Помогаю мамам выйти из выгорания за 6 недель») + подсказка про длину.
- **Кнопка называет результат**: «Собрать оффер», «Сгенерировать лендинг».
- **Результат потоком, по словам**, сразу с кнопками «Копировать» и «Сгенерировать ещё». По возможности 2-3 варианта сразу.

Эти приёмы убирают три страха новичка: чистого листа (примеры), сложности (один экран, мало полей), «зависло/непонятно что вышло» (потоковый текст + копировать).

## 2. Красивый дизайн

Как сделать современно и приятно.

### Источники-ориентиры

- **Linear** — https://linear.app — эталон тёмного «премиум-минимализма»: глубокий фон, тонкие градиенты, свечение, микро-анимации.
- **Vercel / Geist** — https://vercel.com/geist/colors · https://vercel.com/font — светлый «галерейный» минимализм: много белого воздуха, почти чёрный текст, тени вместо рамок.
- **Notion** — https://www.notion.com — тёплый дружелюбный стиль: пастельные карточки, фиолетовая кнопка, мягкие тени. Ближе всего к нашей аудитории.
- **Framer (тренды 2025)** — https://www.framer.com/blog/web-design-trends/ — мягкие тени, скругления, живые градиенты, микро-анимации.
- **Mobbin — палитра Linear** — https://mobbin.com/colors/brand/linear — точные hex бренда.
- **Saaspo** — https://saaspo.com/industry/ai-saas-websites-inspiration — 220+ живых лендингов AI-сервисов.
- **SaaS Landing Page** — https://saaslandingpage.com — 940+ примеров лендингов.

### 5-7 идей для дизайна

1. **Шрифт Inter или Geist + крупные «сжатые» заголовки.** Inter (бесплатный, как у Linear/Notion) или Geist Sans (Vercel). Заголовки большие, с `letter-spacing: -1px … -2px` — выглядит «инженерно» и дорого. Тело — Inter 16px, высота строки ~1.55. *Откуда:* Vercel Geist, Notion, Linear.

2. **Тени вместо рамок.** Вместо серых границ — «рамка из тени»: `box-shadow: 0 0 0 1px rgba(0,0,0,0.08)`; приподнятые карточки — `0 4px 12px rgba(15,15,15,0.08)`. *Откуда:* Vercel, Notion.

3. **Единая шкала скруглений: 8 / 12 / 999px.** Кнопки и поля — 8px, карточки и блоки цен — 12px, бейджи-таблетки — круглые. *Откуда:* Notion.

4. **Пастельные карточки фич под тёплую аудиторию.** Мягкие тёплые заливки: персик `#ffe8d4`, роза `#fde0ec`, мята `#d9f3e1`, лаванда `#e6e0f5`, небо `#dcecfa`. Для психологов/коучей теплее, чем чёрно-белое. *Откуда:* Notion.

5. **Один яркий акцент на кнопке + спокойный фон.** Главный CTA — индиго/фиолетовый: `#5E6AD2` (Linear) или `#5645d4` (Notion), нажатие чуть темнее (`#4534b3`). Остальное — нейтральные серые. *Откуда:* Linear, Notion.

6. **Живой градиент / лёгкое свечение в hero.** Мягкое многоцветное свечение под заголовком (как у Linear: тёмный фон + цветные «дымки» и блюр). В светлой теме — нежный двухцветный градиент. Без перегруза. *Откуда:* Linear, Framer-тренды.

7. **Воздух и микро-анимации.** Большие отступы между секциями (64–120px), много пустого пространства, лёгкие hover-эффекты и плавное появление при скролле. *Откуда:* Vercel, Framer-тренды.

### 2-3 эталона для равнения

1. **Notion** (https://www.notion.com) — **главный ориентир**. Тёплый и человечный стиль, а не «технологичный»: тёмно-синий hero, фиолетовая кнопка, пастельные карточки, мягкие тени, скругления 8/12px. Ровно тот тон, что нужен для психологов и коучей.
2. **Linear** (https://linear.app) — ориентир по **премиальности**: тёмная тема + тонкие градиенты + свечение + точная типографика (Inter). Берём приём «тёмный hero со свечением» и индиго `#5E6AD2`.
3. **Vercel / Geist** (https://vercel.com) — ориентир по **чистоте**: белый фон `#ffffff`, почти чёрный текст `#171717`, тени вместо рамок, воздух, сжатые заголовки.

### Что берём в наш проект

- **База:** светлый или тёмно-синий фон, шрифт **Inter**, крупные заголовки со сжатием букв.
- **Цвета:** нейтральные серые + **один акцент** — индиго/фиолетовый (`#5E6AD2` / `#5645d4`) на главной кнопке.
- **Карточки:** скругление 12px, тень `0 4px 12px rgba(15,15,15,0.08)`, «рамка из тени» вместо серых границ.
- **Теплота:** пастельные заливки блоков (персик/лаванда/мята) — как у Notion.
- **Объём:** много воздуха (64–120px), мягкое свечение в hero, лёгкие hover-анимации.
- **Тон — Notion**, премиальность — Linear, чистота — Vercel.

## 3. Способ разработки

Как технически проще всего собрать сервис новичку.

### Реальные примеры/шаблоны

- **adrianhajdin/saas-template** — https://github.com/adrianhajdin/saas-template — Next.js + Supabase + Clerk + Stripe. Самый «учебный», с обучающими видео.
- **KolbySisk/next-supabase-stripe-starter** — https://github.com/KolbySisk/next-supabase-stripe-starter — Next.js + Supabase + Stripe + shadcn/ui. Каркас «логин + подписка + оплата» почти под наш сценарий.
- **ixartz/SaaS-Boilerplate** — https://github.com/ixartz/SaaS-Boilerplate — Next.js + Tailwind + shadcn/ui. Богатый, но тяжеловат для новичка.
- **NextJSTemplates/openai-nextjs-starter** — https://github.com/NextJSTemplates/openai-nextjs-starter — Next.js + OpenAI, пример «обёртки над AI».
- **vercel/ai (AI SDK)** — https://github.com/vercel/ai — библиотека: один код работает с OpenAI, Anthropic (Claude), Google — меняешь одну строку.
- **imbhargav5/nextbase-nextjs-supabase-starter** — https://github.com/imbhargav5/nextbase-nextjs-supabase-starter — чистый бесплатный старт «кабинет + база».

Вывод по примерам: большинство реальных AI-SaaS собраны по одной формуле — **Next.js + Supabase + Stripe + Vercel AI SDK**. Это проторённая дорога с максимумом шаблонов и инструкций.

### Разбор по слоям

- **Фронтенд + кабинет:** **Next.js** (https://nextjs.org) — один проект = сайт + кабинет + API. **shadcn/ui + Tailwind** (https://ui.shadcn.com) — готовые красивые компоненты.
- **База данных:** **Supabase** (https://supabase.com) — PostgreSQL «под ключ» в облаке, бесплатный тариф, настройка кликами.
- **Авторизация:** **Supabase Auth** (вход встроен) — регистрация по почте, вход через Google. Альтернатива — **Clerk** (https://clerk.com), но это отдельный сервис.
- **Подключение AI:** **Vercel AI SDK** (https://ai-sdk.dev) — `streamText({ model, prompt })`, текст печатается в реальном времени, модель меняется одной строкой (`@ai-sdk/openai`, `@ai-sdk/anthropic`).
- **Оплата:** **Stripe** (https://stripe.com) — стандарт, но **карты РФ не принимает**. **ЮKassa** (https://yookassa.ru) — карты Visa/MC/Мир, **подписки и автосписания** (нужно для автоворонки). Подключение только для самозанятого / ИП / ООО.
- **Хостинг:** **Vercel** (https://vercel.com) — деплой в клик, но из РФ бывает недоступен и карты РФ не принимает (для теста). Боевой на РФ-аудиторию — **Amvera** (https://amvera.ru), **Timeweb Cloud** (https://timeweb.cloud), **RelaxDev** (https://relaxdev.ru/deploy/nextjs).

**Российские реалии по AI (важно):** OpenAI API в РФ заблокирован и не принимает карты РФ. Решения:
1. **ProxyAPI** (https://proxyapi.ru) — российский шлюз к OpenAI / Claude / Gemini, оплата рублями, без VPN. В коде меняется адрес и ключ.
2. **GigaChat от Сбера** (https://developers.sber.ru/portal/products/gigachat) — полностью российский, бесплатный лимит (≈1 млн токенов/год), хорош в русском. Есть OpenAI-совместимый прокси `gpt2giga` (https://github.com/ai-forever/gpt2giga).
3. **YandexGPT** (https://yandex.cloud/ru/services/yandexgpt) — российский, оплата через Яндекс Облако.

### Рекомендованный простой стек для новичка

| Слой | Берём | Почему для новичка |
|---|---|---|
| Фронтенд + кабинет | **Next.js + shadcn/ui** | Один проект на всё, море шаблонов и видеоуроков, готовые компоненты. |
| База данных | **Supabase** | База «под ключ», бесплатный старт, настройка кликами. |
| Авторизация | **Supabase Auth** | Вход встроен в ту же Supabase — меньше сервисов. |
| Подключение AI | **Vercel AI SDK** + **ProxyAPI** или **GigaChat** | Один код, модель меняется строкой; ProxyAPI даёт OpenAI/Claude из РФ за рубли; GigaChat свой и с бесплатным лимитом. |
| Оплата | **ЮKassa** | Карты РФ и Мир, подписки/автосписания, готовый виджет. |
| Хостинг | старт **Vercel** → боевой **Amvera/Timeweb** | Vercel для теста; для РФ-аудитории — российский PaaS за рубли. |

**Почему этот стек самый простой:** меньше всего своего кода (Next.js объединяет фронт и бэк, Supabase даёт базу+вход, AI SDK прячет сложность, ЮKassa даёт виджет); есть готовые шаблоны почти под весь сценарий; лучшая документация по связке Next.js + Supabase; страховка от блокировок (смена AI-провайдера одной строкой, российский хостинг и оплата за рубли).

### Что берём в наш проект

Проверенная дорога: **Next.js (сайт + кабинет) + Supabase (база и вход) + Vercel AI SDK (генерация) + ЮKassa (оплата) + хостинг Amvera/Timeweb**.

Стартуем с готового шаблона `adrianhajdin/saas-template` или `KolbySisk/next-supabase-stripe-starter` и адаптируем под РФ:
- AI через **ProxyAPI** (Claude/OpenAI за рубли) или **GigaChat**;
- оплату Stripe заменяем на **ЮKassa** (нужен статус самозанятого/ИП/ООО);
- тестируем на Vercel, потом переносим на российский хостинг.

Под «автоворонку» важно: ЮKassa поддерживает **рекуррентные платежи (автосписания)** — закрывает регулярную оплату без отдельного сервиса.

> Оговорка: ссылки и репозитории реальны, но цены, лимиты бесплатных тарифов и условия подключения ЮKassa/ProxyAPI/GigaChat стоит перепроверить на их сайтах перед запуском — они меняются.
