# CLAUDE.md — estimate-bot

Telegram-бот для расчёта смет объектов (материалы + работы).

## Ключевые принципы (Карпати)

1. **Думай перед кодингом** — ТЗ есть в `019f.../plan.md`, уточнения документированы
2. **Простота** — минимум кода, никаких спекуляций, только то, что нужно
3. **Хирургические правки** — трогаем только необходимое, не переделываем соседний код
4. **Цель-ориентированное выполнение** — критерии успеха ясны, тестируем перед коммитом
5. **Никогда секреты в коде** — только `.env`, никогда не коммитим `TELEGRAM_TOKEN`, ключи API

## Архитектура

```
main.py                 ← Telegram handlers (ЗАПРЕТ на арифметику)
  ↓
pdf_extract.py          ← pdfplumber + OpenRouter LLM → список позиций
  ↓
search.py               ← Serper.dev + OpenRouter LLM → рыночные цены
  ↓
calculator.py           ← ★ Decimal-only math + verify (не LLM!)
  ↓
excel_report.py         ← Экспорт ТОЛЬКО если verified=True
```

## Правила калькулятора (священное)

- **Единственный источник истины:** `calculator.py::calculate_estimate() + verify_estimate()`
- **Никогда float:** только `Decimal`, округление HALF_UP до копеек
- **Двойная проверка:** verify пересчитывает всё независимо, ловит ошибки
- **Жёсткое правило:** `if not estimate.verified: raise RuntimeError(...)`

## Тестирование

```bash
pytest tests/test_calculator.py -v
```

Обязательно перед каждым коммитом:
- Все тесты зелёные
- Нет hardcoded ключей в коде
- `.env` в `.gitignore`

## Секреты

```bash
# Создай .env (не коммитай!)
cp .env.example .env
# Заполни реальные значения:
# - TELEGRAM_TOKEN (BotFather)
# - OPENROUTER_API_KEY
# - SERPER_API_KEY
# - ALLOWED_USER_IDS (твой Telegram ID)
```

Если случайно закоммитил секрет:
1. Отозови ключ сразу (он скомпрометирован)
2. Удали из истории git: `git filter-branch`
3. Пересоздай ключ в сервисе

## Go / No-Go

**Можно разрабатывать?** Да, MVP полностью специфицирован.

**Что обязательно в v1?** PDF → цены → **calculator+verify** → Excel.

**Главный принцип:** LLM ищет и структурирует; **код считает и перепроверяет**.
