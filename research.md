# Исследование: ИИ-боты для ведения соцсетей

> Контекст: фрилансер-веб-разработчик хочет агента, который сам составляет контент-план, пишет посты для Telegram/VK/Instagram/Дзен, мониторит конкурентов и публикует после согласования.

---

## 1. KonturSMM (kontursmm.ru)

**Какую задачу решает:**
Полный цикл контент-планирования: ниша → рубрики → план на неделю → пакет черновиков.

**Ключевые функции:**
- Онбординг с вопросами о нише, продукте и аудитории
- Автоматическое деление контента по рубрикам (польза / кейс / личное / продажа)
- Генерация контент-плана на 7 дней
- Пакетная генерация 15 черновиков за один запрос

**Типичный диалог:**
```
Бот:  Привет! Расскажи о проекте — чем занимаешься, кому продаёшь?

Ты:   Я веб-разработчик, делаю сайты для малого бизнеса.
      Хочу вести Telegram-канал, чтобы привлекать клиентов.

Бот:  Понял. Предлагаю 4 рубрики:
      1. До/после — кейсы с результатами
      2. Разбор ошибок — что не так у конкурентов клиента
      3. За кулисами — процесс работы
      4. Польза — советы по сайтам

      Вот план на 7 дней + 15 черновиков. Редактировать?
```

**Что делает его полезным:**
Мыслит как SMM-стратег, а не просто генерирует текст. Сразу даёт структуру с рубриками.

**Что взять для нашего бота:**
- Онбординг с вопросами о нише при первом запуске
- Автоматические рубрики (не один стиль постов, а разные форматы)
- Пакетная генерация: не один пост, а сразу блок на неделю

## 2. ChatPost (chatpost.ru)

**Какую задачу решает:**
Создание поста из любого входного формата — голос, текст, ссылка, картинка.

**Ключевые функции:**
- Пост из голосового сообщения (надиктовал идею — получил текст)
- Пост из YouTube-видео или статьи (ссылка → пересказ постом)
- Пост по фото (снимок результата → готовый кейс)
- Адаптация одного контента под несколько платформ
- Сценарии для Reels/Shorts

**Типичный диалог:**
```
Ты:  [голосовое 30 сек]
     "Сделал редизайн сайта для кафе, они были в ужасе от старого,
     теперь очень довольны, конверсия выросла"

Бот: Готово! Вот пост для Telegram:
     [кейс на 1500 знаков с хуком, историей и CTA]

     Адаптировать под VK или Instagram?
```

**Что делает его полезным:**
Минимальный порог входа. Занятой фрилансер просто говорит вслух — бот делает пост.

**Что взять для нашего бота:**
- Голосовой ввод как режим взаимодействия (killer-feature)
- Адаптация одного материала под все платформы в один клик

## 3. SMMplanner + Геннадий (smmplanner.com / @smmgenabot)

**Какую задачу решает:**
Самый полный инструмент на рынке СНГ: генерация идей + написание постов + согласование + автопубликация в 11 соцсетей.

**Ключевые функции:**
- AI SMM-щик: анкета о бизнесе → мониторинг трендов → контент-план на месяц
- Бот Геннадий: генерация идей и текстов прямо в Telegram
- Шаг согласования: публикует только после одобрения
- Поддержка: Telegram, VK, Instagram, Дзен, TikTok, YouTube
- Аналитика охватов и вовлечённости после публикации

**Типичный диалог:**
```
Ты:    Дай 5 идей для постов про веб-разработку. Аудитория — малый бизнес.

Бот:   1. "3 признака, что ваш сайт теряет клиентов прямо сейчас"
       2. "Как мы подняли конверсию с 0,8% до 3,2%"
       3. "Сайт за 50 000 vs 500 000 — в чём реальная разница"
       4. "Почему ваш подрядчик молчит неделями"
       5. "Разбираю сайт подписчика: что сделал бы иначе"

       Написать пост по одной из идей?

---

SMMplanner: Пост запланирован на завтра в 10:00 в Telegram, VK и Дзен.
            Подтвердить публикацию?

Ты:         Да

SMMplanner: Опубликовано. Охват через 2 часа: 340 чел., 3 репоста, 12 реакций.
```

**Что делает его полезным:**
Единственный сервис, где есть реальный цикл: план → текст → согласование → публикация → аналитика.

**Что взять для нашего бота:**
- Флоу "идеи → выбор → пост → согласование → публикация" как основная модель
- Аналитика после публикации для обучения (что заходит у конкретного автора)
- Учёт праздников при распределении постов по датам

## 4. SmmBox (smmbox.com)

**Какую задачу решает:**
Автопостинг в 12 соцсетей, включая Яндекс Дзен. Лучшая поддержка Дзена из всех сервисов.

**Ключевые функции:**
- Публикация в VK, Telegram, Instagram, Дзен, Одноклассники, TikTok, YouTube, RuTube
- RSS-поиск контента: подписка на источники → автоматические посты
- Встроенная нейросеть для написания текстов
- Telegram-бот для управления публикациями

**Что делает его полезным:**
Единственный из популярных сервисов с полноценной поддержкой Яндекс Дзен.

**Что взять для нашего бота:**
- Механику публикации в Дзен (копирует пост из другой соцсети и адаптирует в статью)
- RSS-мониторинг как источник контент-идей из новостей ниши

## 5. Twexel (twexel.ru)

**Какую задачу решает:**
Автопостинг в Telegram и VK с открытым API — идеален как "рука публикации" для кастомного агента.

**Ключевые функции:**
- Публикация в Telegram-каналы, группы, VK
- Открытый API + webhook: внешняя система отправляет пост → Twexel публикует
- AI-генерация текстов внутри редактора
- RSS-постинг: подключаешь источники новостей → автопосты

**Что делает его полезным:**
Единственный сервис с webhook, который позволяет нашему агенту отправлять готовые посты через API и не зависеть от ручного ввода.

**Что взять для нашего бота:**
- Twexel API как движок публикации: агент генерирует → Twexel публикует
- Архитектура: агент (мозг) + Twexel (руки)

## 6. Metricool (metricool.com)

**Какую задачу решает:**
Планирование + аналитика + мониторинг конкурентов + адаптация контента под платформы.

**Ключевые функции:**
- AI-репурпозинг: URL статьи → посты для каждой платформы в отдельном стиле
- Мониторинг до 5 конкурентов бесплатно (рост, охваты, топ-посты)
- Лучшее время публикации на основе статистики аккаунта

**Типичный диалог:**
```
Вход:  [URL статьи "Как фрилансеру найти первых клиентов"]

Выход:
  Telegram: 3 абзаца + эмодзи, вопрос к аудитории в конце
  Instagram: 5 коротких пунктов для карусели
  Дзен: статья 800 слов с заголовком
```

**Что делает его полезным:**
Репурпозинг одного материала в разные форматы автоматически. Экономит 80% времени на адаптацию.

**Что взять для нашего бота:**
- Разные промпты под каждую платформу (не один текст для всех)
- Данные о лучшем времени публикации

## 7. n8n + ChatGPT API (кастомная архитектура)

**Какую задачу решает:**
Полностью автономный пайплайн: мониторинг конкурентов → генерация тем → написание постов → публикация. Без ручного труда.

**Ключевые функции:**
- Сбор идей из RSS конкурентов и новостей ниши
- ChatGPT API генерирует текст с нужным промптом под каждую платформу
- Публикация через Telegram Bot API, VK API, Дзен API
- Google Sheets как база "что уже постили" (чтобы не повторяться)

**Архитектура:**
```
RSS конкурентов → n8n → ChatGPT API → адаптация под платформу
                                     → Telegram Bot API
                                     → VK API
                                     → Дзен API
```

**Что делает его полезным:**
Самый гибкий вариант. Разработчик сам контролирует промпты и логику.

**Что взять для нашего бота:**
- Эта архитектура — основа нашего агента
- Хранение опубликованных тем в базе (не повторяться)
- Мониторинг RSS как источник контент-идей

## Главный вывод

**Готового агента для нашей задачи не существует.** Самый близкий — SMMplanner, но он не делает мониторинг конкурентов и требует ручного ввода тем.

Оптимальная архитектура нашего агента:
1. **Мозг:** ChatGPT/Claude API — генерация контент-плана и текстов
2. **Источники:** RSS + TGStat + Popsters — мониторинг конкурентов и трендов
3. **Интерфейс:** Telegram-бот — управление, голосовой ввод, согласование
4. **Руки:** Twexel API (Telegram+VK) + SmmBox (Дзен) + Instagram Graph API

Это собирается за 2-4 недели и заменяет 5 отдельных сервисов.

## Техники промптинга для "голоса бренда"

Лучшие боты используют три подхода:

**1. Анализ существующих текстов:**
```
"Вот три моих поста. Проанализируй стиль и запомни его как 'мой голос'.
Теперь пиши все тексты в этом же стиле."
```

**2. Онбординг-анкета при первом запуске:**
- Опиши свою услугу в одном предложении
- Кто твой идеальный клиент?
- 3 прилагательных, описывающих твой стиль общения
- Что ты никогда не напишешь в своём аккаунте?

**3. Persona prompting:**
```
"Ты — Удача, веб-разработчик-фрилансер с 7 годами опыта.
Пишешь просто, без воды, с лёгкой иронией.
Аудитория — малый бизнес, устал от агентств.
Запрещённые слова: синергия, экосистема, интегрированный.
Напиши пост на тему: [тема]"
```
