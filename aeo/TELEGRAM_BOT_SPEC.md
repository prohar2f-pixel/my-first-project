# 🤖 Telegram-бот для управления AEO кампанией
## Переделка @AiProharKontent_bot под AEO задачи

---

## 📋 Основные функции

### 1. **Управление контентом (Writing)**
```
/start → Menu
├─ 📝 Написать статью
│  ├─ Выбрать из 5 готовых тем
│  ├─ Указать площадку (VC.ru / Habr / Dzen)
│  ├─ Указать размер (S/M/L)
│  └─ Бот пишет Draft через Claude API
├─ 📋 Мой контент (список всех статей)
├─ 📅 Календарь публикаций
└─ 📊 Статистика
```

### 2. **Публикация и промоция**
```
/publish статья_id → 
├─ Скопировать готовый текст
├─ Ссылка где публиковать (с инструкцией)
├─ Напоминание о правилах каждой площадки
└─ Сохранить ссылку на опубликованный материал
```

### 3. **Отслеживание результатов**
```
/track → 
├─ Просмотры (вручную вводим из analytics)
├─ Комментарии (сводка ключевых)
├─ Упоминания в ChatGPT/Perplexity (вводим вручную)
├─ Трафик на aiprohar.ru (из GA)
└─ Общий прогресс (%)
```

### 4. **Тестирование в AI**
```
/test_gpt → 
├─ Список промтов для ChatGPT
├─ Список промтов для Perplexity
├─ Проверил ли я? (Yes/No)
└─ Результат (есть ли упоминание)

/test_schedule →
├─ Напоминание тестировать каждый понедельник
├─ История результатов
└─ Тренд (растёт ли видимость)
```

### 5. **Напоминания и планирование**
```
/reminders →
├─ 📝 Написать статью #X до ДД.ММ
├─ 📤 Опубликовать статью #X на Площадка до ДД.ММ
├─ 🧪 Протестировать в ChatGPT до ДД.ММ
├─ 📊 Обновить метрики до ДД.ММ
└─ (настраивается на каждую стадию)
```

### 6. **Кейсы и результаты**
```
/cases →
├─ Добавить новый кейс (форма)
├─ Список кейсов (редактируемый)
├─ Когда готовые кейсы опубликовать
└─ Ссылка на опубликованный кейс
```

## 🔄 Workflow (пример)

**День 1 (Написание):**
```
Я: /new_article
Бот: "Выбери тему (1️⃣-5️⃣)"
Я: 1 (AEO vs SEO)
Бот: "Выбери площадку"
Я: VC.ru
Бот: "Выбери размер: S/M/L"
Я: M
Бот: "Пишу... ⏳" (обращается к Claude API)
[Готовый Draft в сообщении]
Я: Одобряю
Бот: "Сохранил как Draft #1. Следующий шаг - публикация на ДД.ММ"
```

**День 3 (Публикация):**
```
Бот (напоминание): "Пора публиковать 'AEO vs SEO' на VC.ru!"
Я: /publish 1
Бот: "
Шаг 1: Скопируй текст 👇
Шаг 2: Перейди на vc.ru/post
Шаг 3: Вставь, отредактируй теги
Шаг 4: Опубликуй и скинь ссылку мне
"
Я: [ссылка на опубликованную статью]
Бот: "Сохранил! Статья #1 опубликована. Жди результатов..."
```

**День 10 (Отслеживание):**
```
Бот (каждый понедельник): "Время обновить метрики! 📊
Статья #1 на VC.ru - сколько просмотров?"
Я: 1500
Бот: "Комментарии?"
Я: 15 (качественных)
Бот: "Упоминается в ChatGPT?"
Я: Да, 2 раза видел
Бот: "Отлично! 📈 Прогресс: 23% к цели"
```

## 🚀 MVP (первый этап)

**Что реально нужно:**
1. `/new_article` - выбор темы + генерация Draft через Claude
2. `/publish` - инструкции для публикации + сохранение ссылки
3. `/track` - ввод metrics вручную + сводка
4. `/test_gpt` - напоминание + отслеживание результатов
5. `/reminders` - встроенные напоминания на сроки

**Что отложить на v2:**
- Автоматическая публикация на VC/Habr (нужны API ключи)
- Автоматический парсинг просмотров (нужны GA4 API)
- Автоматический парсинг ChatGPT (можно, но сложно)

## 🛠️ Технические детали

**Стек:**
- Python + python-telegram-bot
- Claude API для генерации текста
- Простая БД (SQLite или JSON)
- Если сложно - можно через Google Sheets API

**Развертывание:**
- VPS 195.2.85.114 (есть у пользователя)
- Или Railway (как текущий audit-bot)

**Интеграции:**
- Claude API (для написания статей)
- GA4 API (для трафика, опционально)
- VC.ru, Habr (пока вручную через инструкции)
