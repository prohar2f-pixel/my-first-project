# 🔧 ПЕРЕДЕЛАННАЯ СТРАТЕГИЯ V2: Кейсы First (не Статьи)
## Реальный план попадания в ChatGPT через результаты, не через слова

---

## ❌ ЧТО БЫЛО НЕПРАВИЛЬНО В V1

| Было | Проблема | Почему не работает |
|-----|----------|-------------------|
| 5 статей на VC/Habr | Люди не верят без кейсов | Статья без доказательства = маркетинговая шумиха |
| "Попасть в ChatGPT" | Нет контроля, нет срока | ChatGPT не гарантирует ничего |
| Фокус на инструмент | Инструмент = конкуренция с HubSpot Free | Не уникально |
| Telegram-бот для управления | Лишняя работа | Сначала нужны результаты, потом автоматизация |
| SMB позиционирование | Слишком узко и дешево | 50k = 50 часов работы = не выгодно |

**Вывод:** V1 = маркетинг без результатов. Нужно начать с результатов.

## ✅ НОВАЯ СТРАТЕГИЯ: КЕЙСЫ ВМЕСТО СТАТЕЙ

### **Фаза 1 (1–14 июля): РЕАЛЬНЫЕ КЕЙСЫ**

#### **Шаг 1.1: Найти 3 клиентов (на условиях соавторства)**

**Тактика:**
```
Напишешь 20 человекам в LinkedIn:
"Ищу 3 стартапа/малого бизнеса для case study.
Сделаю бесплатный аудит + покажу результаты.
Если будет успех — напишешь отзыв и разрешишь мне опубликовать кейс.
Если не будет — никаких обязательств."

Цель: 3 согласившихся (из 20 попробует ~15%)
```

**Кого искать:**
- SaaS стартапы (AI tools, productivity apps)
- Digital агентства (которые сами нуждаются в видимости)
- B2B сервисы (где Google трафик дорог)

**Что избегать:**
- e-commerce (очень сложно показать результат в ChatGPT)
- Локальный бизнес (Alice не развивается)
- Компании, которые уже платят NeuroReach ($400k/месяц у них, а не у тебя)

---

#### **Шаг 1.2: Сделать аудит каждому (настоящий, не фейк)**

**За 5–10 часов на каждого:**

```
1. Запустить AEO Generator (свой или HubSpot)
   └─ Проверить текущую видимость в ChatGPT/Perplexity

2. Запустить 20 реальных промтов в ChatGPT вручную:
   "как выбрать [их категорию]?"
   "лучшие [их ниша]"
   "где найти [их услугу]?"
   └─ Записать: упоминается ли клиент? (да/нет)

3. То же для Perplexity (те же 20 промтов)

4. Проверить текущую структуру сайта:
   ├─ Entity правильно ли описана?
   ├─ Заголовки правильные?
   ├─ FAQ есть?
   └─ Контент "answer-ready"?

5. Написать рекомендации (5–7 конкретных действий):
   - Что переделать на сайте
   - Какой контент создать
   - Где разместить упоминания
   └─ Сроки (реалистичные: 4–8 недель)

6. Составить письменный отчёт (3–5 страниц)
```

**Результат:** Клиент видит:
- ✅ Где его сейчас НЕТ в ChatGPT
- ✅ Конкретный план что делать
- ✅ Сроки
- ✅ Твоё ноу-хау, а не просто слова

---

#### **Шаг 1.3: Провести изменения (вместе с клиентом)**

**Твоя роль: Консультант (не исполнитель)**

```
Варианты работы:

Вариант A: "Я консультирую, ты исполняешь" (бесплатно)
├─ Это даст тебе кейс
├─ Клиент видит, что помогаешь
└─ Если успех — упоминание в публикации

Вариант B: "Я делаю всё, ты платишь 50k" (полный пакет)
├─ Ты получаешь гарантию (50k = серьёзно)
├─ Клиент платит за результат
└─ Если успех → 50k + кейс

Вариант C: Гибрид
├─ Клиент платит 15k за консультацию (план)
├─ Потом сам исполняет или нанимает фрилансера
└─ Ты отслеживаешь и помогаешь
```

**Что делать в консультировании:**
- Еженедельные check-ins (30 минут)
- Письма по результатам
- Корректировки плана если не работает
- Помощь с контентом (подсказки, не написание)

**Сроки:** 4–8 недель работы (зависит от клиента)

---

#### **Шаг 1.4: Отслеживать результаты (честно)**

**Метрики для каждого клиента:**

```
Неделя 1–2:
├─ Запущены ли изменения на сайте? (да/нет)
└─ Какие именно? (конкретно)

Неделя 3–4:
├─ Упоминается ли уже в ChatGPT? (1–2 промта?)
└─ Если нет — почему? (анализ)

Неделя 5–8:
├─ Сколько промтов дали результат?
├─ Трафик изменился? (из Analytics)
├─ Лиды пришли? (если есть форма)
└─ Что сработало / не сработало?

Финал:
├─ "Было X упоминаний, стало Y"
├─ "Трафик вырос на Z%"
└─ "Это стоит денег?" (честно)
```

**ЧЕСТНЫЙ результат важнее позитивного:**
- Если не сработало: "Вот почему (пример: контент не answer-ready)"
- Если частично: "Пойдёт в 3 запросах из 20 (это 15% успеха)"
- Если сработало: "Отлично, тут сработал вот этот элемент"

└─ Полный пакет 50–150k

✅ Стало:

ВАРИАНТ A (КОНСУЛЬТАНТ):
├─ Аудит: 5k (и точка)
├─ Консультация (4 недели): 15k (и точка)
├─ Лиды по результатам первого месяца
└─ "Если не видишь результата — половину возвращу"

ВАРИАНТ B (ПОЛНЫЙ ПАКЕТ):
├─ Всё вместе: 49k (и точка)
├─ Включает: аудит + план + консультацию 8 недель
├─ Гарантия: "Упоминание в минимум 1 запросе"
└─ Если нет гарантии — полный возврат

ВАРИАНТ C (ТОЛЬКО АУДИТ + ПЛАН):
├─ Цена: 10k (и точка)

└─ CTA: "Потом помогу монитить за 2k/месяц"

**Почему так?**
- Прозрачность: нет путаницы
- Серьёзность: низкая цена = клиенты не ценят результат
- Гарантия: показываешь уверенность
- Масштабируемость: если работает — легко масштабировать
